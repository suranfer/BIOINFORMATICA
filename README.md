# Cuaderno de prácticas 
Hola! Este repo es mi cuaderno de prácticas de la asignatura de Bioinformática :)

## Índice
En `doc/` encontrarás las referencias bibliográficas utilizadas en los guiones de las prácticas.

En `results/` se reúnen las carpetas, organizadas por fecha de realización, de cada práctica. Dentro de cada una **siempre** estará el guión en formato .qmd, con todo el código utilizado, y el guión en formato HTML, más limpio y fácil de seguir. De forma adicional, también están disponibles aquellos archivos de resultados generados a partir de los análisis ejecutados en el guión que, por su tamaño, fuera factible subir a Git.

## Requisitos
La **terminal de Bash** y **RStudio** son los 2 entornos fundamentales para el desarrollo de las prácticas.

En mi caso, necesité recurrir a WSL para tener acceso a las facilidades de Linux (ya que mi sistema operativo es Windows) y trabajé desde RStudio Server.

En cuanto a los programas, paquetes o dependencias utilizados, en cada guión se especifica cuáles serán necesarios y cómo instalarlos. Del mismo modo con los datos: se indica cuáles son necesarios para cada análisis y dónde encontrarlos.

Dicho esto, espero que os sea útil y os sirva de ayuda.

Gracias!
